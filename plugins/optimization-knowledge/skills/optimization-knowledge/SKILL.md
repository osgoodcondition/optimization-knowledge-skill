# Optimization Knowledge

This plugin provides a reviewed, source-linked reference collection. For an optimization question, read [the reference index](references/index.md), then open only the notes relevant to the question. A note's `source`, `scope`, and `status` describe what was checked; do not treat material outside that scope as verified.

For a user-provided paper, read the sections needed to answer the question. State the source and page or section for claims drawn from it. Keep theorem assumptions and conclusions, proof steps, experimental observations, your own explanation, and conjectures distinct. Check a claim against the original paper when the answer depends on its exact wording, notation, or conditions. If the source or a page is unavailable, say what remains unverified.

After answering a request to read an optimization paper, summarize only the parts actually read, with source and page or section, in the user's designated writable personal notes. Update an existing note for the same paper and its index rather than creating duplicates. For other optimization discussions, save reusable insights there when the user has requested ongoing note-taking. Honor a request not to save. If no writable personal location has been designated, ask for one before saving.

The installed reference collection is a reviewed release. Do not edit it to store personal notes or silently add claims. External contributions to the public collection must go through a pull request and maintainer review, with primary sources and exact scope. Follow the repository's contribution rules when preparing a submission.
